Strategy Selection Guide
Best for ORB Breakouts
  • High Average Daily Range (ADR > 0.8%)
  • Minimum 20L+ shares traded per day
  • Strong trending behavior (not range-bound)
  • Tight bid-ask spreads in options chain
Best for VWAP Pullbacks
  • Institutional participation (FII/DII flows)
  • Respects technical levels consistently
  • Banking & financial stocks work best
  • Avoid low-float or news-driven tickers
API Configuration
Set your Upstox API credentials in app.py at the top of the file, or use environment variables: 
# Option 1: Edit app.py directly
CLIENT_ID     = 'your_client_id_from_upstox_console'
CLIENT_SECRET = 'your_client_secret'

# Option 2: Environment variables (recommended for security)
export UPSTOX_CLIENT_ID=your_client_id
export UPSTOX_CLIENT_SECRET=your_client_secret

# Then run:
python app.py
Get your credentials at developer.upstox.com → Create App → Redirect URI must be http://localhost:8080/callback
Strategy Logic Reference
LONG Entry
✓ 5-min candle closes ABOVE OR High
✓ Close price is ABOVE VWAP
✓ Volume ≥ 75% of session average
✓ Entry after 9:30 AM (OR complete)
✓ No trades after 2:00 PM
SHORT Entry
✓ 5-min candle closes BELOW OR Low
✓ Close price is BELOW VWAP
✓ Volume ≥ 75% of session average
✓ Entry after 9:30 AM (OR complete)
✓ No trades after 2:00 PM
Exit Rules
🔴 Stop Loss → OR Low (LONG) / OR High (SHORT)
🟡 Target 1 → Entry ± 1.5× risk → exit 50%
     SL moved to entry price (free trade)
🟢 Target 2 → Entry ± 2.5× risk → exit 50%
⏰ Time Exit → Force close at 3:15 PM
Position Sizing
Risk% of Capital ÷ Risk per lot
= Number of lots (capped at 10)

Example: ₹4L capital, 1% risk = ₹4,000 risk
50pt stop on Nifty (lot 75) = ₹3,750/lot
→ 1 lot
